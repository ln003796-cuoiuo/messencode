# WP Messenger (Blueprint Stage 1)

Это фундамент мессенджера как WordPress-плагина по вашей полной спецификации.

## Что реализовано сейчас

- Один файл плагина с шорткодом `[wp_messenger]`
- Кастомные таблицы `wp_mess_dialogs` и `wp_mess_messages`
- AES-256-GCM шифрование текста сообщений на уровне БД
- REST API для списка чатов, создания чата, чтения/отправки сообщений
- SPA UI (3 колонки desktop, адаптивный mobile)
- Базовый silent-mode при отправке

## Установка

1. Скопируйте файлы в папку плагина, например `wp-content/plugins/wp-messenger/`
2. Активируйте плагин в админке WordPress
3. Создайте страницу и добавьте шорткод:

```txt
[wp_messenger]
```
